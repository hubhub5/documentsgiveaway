편집 원칙

이 사전의 문서를 쓰고 고치는 기준입니다.

문서 단위

  • 문서 하나는 '작은 상황' 하나입니다. 큰 주제는 상위 문서로, 나이마다 크게 다르면 하위 문서로 나눕니다.
  • 모든 문제 문서는 같은 양식을 씁니다: 말 → 신호 → 장면 → 무너지는 흐름 → 원인 → 트리거 → 방법 → 말 바꾸기 → 작은 실천 → 회복 신호 → 한계.
  • 칸마다 글자 수 상한이 있습니다. 긴 설명이 필요하면 개념 문서로 나눠 링크합니다.

출처

  • 학술지에 실린 연구는 DOI를 Crossref 메타데이터와 대조한 뒤에만 싣습니다.
  • 연구 결과를 옮길 때 원문에 없는 수치나 해석을 더하지 않습니다.
  • 후속 연구에서 효과가 작게 나오거나 엇갈린 경우 함께 적습니다. 예: 마인드셋
  • 현장 관찰은 근거 등급 D로 따로 표시합니다.

쓰지 않는 표현

  • ‘~의 모든 것’, ‘핵심은’, ‘중요합니다’, ‘효과적인’, ‘다양한’ 같은 빈 말
  • 느낌표, 이모지, 명령형 권유(‘~해보세요!’)
  • 아이를 유형으로 단정하는 말(‘○○형 아이’)

도서 추천

  • 관련 도서는 문서 내용과 직접 이어지는 책만, 국내 출간이 확인된 책만 올립니다.
  • 일부 링크는 쿠팡 파트너스 링크이며 구매 시 수수료를 받습니다. 추천 여부는 수수료와 무관하게 정합니다.

상태 표시

  • 초안 등재했지만 저자 검토 전
  • 검토됨 저자가 문장과 출처를 확인함
