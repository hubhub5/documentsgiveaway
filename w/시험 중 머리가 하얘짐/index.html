04

무너지는 흐름

  1. 계기

    시험지를 넘기는 순간 첫 문제가 낯설게 보임

  2. 첫 생각

    "하나도 모르겠다"

  3. 감정·몸

    심장이 뛰고 손끝이 차가워짐

  4. 패턴

    첫 문제를 반복해서 읽으며 시간을 흘려보냄

  5. 무너지는 지점

    시간 확인 → 더 큰 공포 → 다음 문제도 안 읽힘

  6. 남는 것

    시험 끝나고 생각나서 더 큰 자책 → 틀리면 바로 자책함

05

왜 거기서 꺾이나

  • 1급한 스트레스가 인출 과정을 막음 → 스트레스와 기억 인출
  • 2걱정이 작업 공간을 차지함 → 시험 불안
  • 3예전에 망친 시험의 기억이 몸에서 먼저 반응함
