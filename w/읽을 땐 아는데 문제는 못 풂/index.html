무너지는 흐름

  1. 계기

    문제의 질문 방식이 교과서 문장과 다름

  2. 첫 생각

    "분명히 읽은 건데"

  3. 감정·몸

    머리가 멍해지고 짜증이 올라옴

  4. 패턴

    문제를 덮고 교과서로 돌아가 다시 읽음

  5. 무너지는 지점

    읽는 시간만 늘고 문제 푸는 시간은 계속 줄어듦

  6. 남는 것

    시험에서 '아는데 틀렸다'가 반복됨 → 아는 문제인데 시험에서 틀림
